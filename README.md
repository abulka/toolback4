# toolback v4

A modern ToolBook spiritual successor. See [PLAN.md](./PLAN.md) for the full plan,
architecture, milestones, and progress tracker.

## Commands

    pnpm install          # setup (corepack enable first if pnpm is missing)
    pnpm dev              # editor dev server (http://localhost:5173)
    pnpm test             # vitest across packages
    pnpm typecheck        # tsc / vue-tsc across packages
    pnpm build            # production build
